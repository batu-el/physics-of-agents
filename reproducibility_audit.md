## Reproducibility Audit

| Area | Finding |
| --- | --- |
| Main simulation and split | Agent count, rounds, vote count, question counts, and random-graph train/test split agree with Section 2 and Appendices B/D. |
| Historical messages | GPT-4o-mini and Gemma-3n-E4B used per-recipient sampling; current code broadcasts one message per sender. This exception is explicitly disclosed in Appendix B.5. |
| Failed opinion samples | Failed opinion samples are stored as `0`, extending the binary-only description. They are rare in the main consolidated data: 0.0377% of raw samples (5,214 / 13,824,000) and 0.00192% of aggregated states (53 / 2,764,800). Their effect on published statistics was not separately measured. |
| Continuous-model fitting | Discrete models use standardized feature columns; continuous models use original feature columns. This matches the revised Appendix D.3, Optimization paragraph. |
| Temperature sweep | The main qualitative trends and conclusion agree with Figure 7 and Section 5.3. Susceptibility peaks at intermediate temperatures and is lower at both ends of the sweep; objective curves have sharper peaks than subjective curves. All eight mean group critical temperatures exceed the fitted operating point `T = 1` (range: 1.36–2.63), consistent with the paper's interpretation of operation below the transition. The corrected notebook follows the group-peak averaging procedure in Appendix E.3 and was rerun successfully. |
| Prediction tables | At printed precision, saved values are not exact matches with the paper in 46/160 entries in Table 1 (mean absolute difference 0.062, maximum 1.2 percentage points), 48/256 in Tables S4–S5 (mean absolute difference 0.056, maximum 1.8 percentage points), and 6/32 in Table S6 (mean absolute difference 0.088, maximum 2.0 percentage points). Means include all entries, including exact matches. The numerical differences preserve the principal prediction conclusions and the best-performing methods. The maximum three-coupling generalization gap is 2.5 percentage points, versus 2.4 stated in the paper. |
| Couplings and thresholds | In Table 3, 43/44 coefficients agree at two decimals; GPT subjective `beta_pos` rounds to 2.38 in the repository versus 2.39 in the paper. Qwen subjective `n*` is 0.6125 in the implementation versus 0.600 in Table S3; the other seven model/regime threshold pairs agree at printed precision. |
| Objective vote share | The Llama notebook's pooled parsed-sample positive vote share is 37.9% initially and 15.1% finally, versus 39% and 16% in Appendix C.2. |
| Frontier results | All 60 displayed one-step/rollout values in Table S7 agree with the saved frontier table at one decimal. |
| Generalization evaluation | [4_prediction_generalization.ipynb](res/4_prediction_generalization.ipynb) now evaluates all four graph families and all 80 entries of Table 2 using the released data. It fits only on the original training questions and eight random training graphs. At printed precision, 32/80 scores differ from the paper (mean absolute difference across all entries: 0.1425 percentage points; maximum: 2.2 points, subjective low-rank mean-field rollout). The winning methods are unchanged: the three-coupling rule is best in 15/16 columns. All 20 fresh-random scores match the current main prediction notebook. |
| Low-rank data and remaining coverage | `data/lowrank/` contains 240 episodes: six graphs × ten test questions × two replicas per regime. The stored adjacency matrices have rank 11, whereas Appendix B.2 specifies a target rank of 10. Objective low-rank evaluation covers 10 of the 20 test questions; the notebook displays this coverage explicitly. The matrices needed for evaluation are stored in each episode. |
| Low-rank construction | The verified topology agrees with the description: a 10-node core with 34 internal edges, plus 22 leaves attached to one core hub. Appendix B.2's fixed edge budget, six graphs, and sign-based frustration variation are consistent with the data, but the prescribed algebraic rank 10 is not: all six matrices have rank 11. Effective rank is 5.92–6.88. Exact frustration fractions are 0, 5/56 or 6/56, and 11/56 for targets 0, 0.1, and 0.2, respectively; the nonzero targets are approximate. See [the data README](data/lowrank/README.md). |
